# Name That LLM

Kaggle: по пассажу определить, какая из 18 LLM его написала.

## Данные

- `train` — 2 699 пассажей: 150 промптов × 18 моделей.
- `test` — ~4 000 пассажей на промптах, которых нет в train.
- Метрика — balanced accuracy по 18 классам.

## Структура

- `src/ntl/` — библиотека: данные, метрика, CV, фичи, модели.
- `src/` — пайплайн: сплит, эмбеддинги, HPO, стек.
- `experiments/` — диагностические скрипты.
- `submit/`, `submit_stack/` — Kaggle-кернелы.
- `splits/` — фиксированные разбиения.
- `AGENT.md` — контекст и текущее состояние.
- [Issues](https://github.com/alexkolesnikov08/name-that-llm/issues) — гипотезы и результаты.

Текущий результат: стек 7 вью — **0.392** balanced accuracy на dev.
Данные соревнования в репозиторий не включены.
